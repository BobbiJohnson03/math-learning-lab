# Papers and reading notes

Notatki z lektury publikacji związanych z analizą stochastyczną i BSDE. **Nie kopiuj treści publikacji** — streszczaj własnymi słowami, notuj potrzebne pojęcia, metodę i swoje pytania.

> Status: ⬜ not-started

## Pliki

- [`reading-order.md`](./reading-order.md) — sugerowana kolejność czytania
- [`paper-template.md`](./paper-template.md) — szablon notatki z artykułu
- [`bibliography.md`](./bibliography.md) — lista pozycji (cytowanie, link, streszczenie)

## Jak dodać notatkę

1. Skopiuj [`paper-template.md`](./paper-template.md) do nowego pliku, np. `2024-autor-tytul.md`.
2. Wypełnij pola; nowe pojęcia przenieś do [`../terminology`](../terminology/) i głównego [`GLOSSARY.md`](../../GLOSSARY.md).
3. Dodaj pozycję do [`bibliography.md`](./bibliography.md).

Ogólny szablon: [`../../templates/paper-note-template.md`](../../templates/paper-note-template.md).
