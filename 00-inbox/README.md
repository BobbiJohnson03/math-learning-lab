# 00-inbox

Folder na **szybkie, jeszcze nieuporządkowane notatki** — miejsce, gdzie zapisujesz pomysły, fragmenty z wykładu, linki i luźne myśli, zanim znajdziesz dla nich właściwe miejsce.

## Zasada

Materiały z inboxa są **tymczasowe**. Podczas cotygodniowego przeglądu (zob. [`templates/weekly-review-template.md`](../templates/weekly-review-template.md)) przenoś je do odpowiedniego działu:

- teoria konkretnej dziedziny → `01`–`09`
- zastosowanie w AI → [`10-ai-ml-mathematics`](../10-ai-ml-mathematics/)
- materiał ze studiów → [`11-university-mathematics`](../11-university-mathematics/)
- procesy stochastyczne / BSDE → [`12-stochastic-analysis-and-bsde`](../12-stochastic-analysis-and-bsde/)

Celem jest, aby inbox był **regularnie opróżniany**, a każde zagadnienie trafiło do swojego jednego kanonicznego miejsca.
